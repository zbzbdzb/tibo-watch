# Tibo Watch 视觉系统

## 视觉基准

- 主仪表盘：`docs/design/tibo-watch-dashboard.png`
- 设置页：`docs/design/tibo-watch-settings.png`
- 不采用任何雷达、圆形扫描、发光或渐变元素。

## 设计令牌

- 页面背景：`#070b0e`
- 侧栏与标题栏：`#0a0f13`
- 行选中背景：`#101a21`
- 主文字：`#eef2f3`
- 次文字：`#9aa6ad`
- 边框：`#263038`
- 确认绿色：`#75df4b`
- 预告琥珀：`#f2aa2f`
- 交互蓝色：`#4ba3ff`
- 危险红色：`#ef6262`

字体使用 `Segoe UI Variable`, `Microsoft YaHei UI`, sans-serif；时间戳使用 `Cascadia Mono`, monospace。边框统一 1px，控件圆角不超过 6px，图标为 1.75px 线性风格。

## 容器与布局

- 1440×900 为视觉基准，最小窗口 1080×720。
- 标题栏 52px，侧栏 188px，底部状态栏 32px。
- 主屏上半部为当前状态与运行状态；下半部为时间线和详情的双栏布局。
- 设置页为左右双栏，窄窗口改为纵向；不使用卡片网格。

## 允许的首屏文案

`Tibo Watch`、`Codex 重置监测`、`总览`、`动态`、`数据源`、`通知`、`设置`、`当前状态`、`已确认重置`、`尚未确认新的重置`、`最近检查`、`下次检查`、`查看原帖`、`运行状态`、`后台监测中 · 每 5 分钟检查`。
