# Tibo Watch — 独立 UI 预览

这是重新设计的浏览器交互原型，不替换正式 Electron 界面，不使用现有 preload 或桌面数据库。

## 启动

在仓库根目录执行（复用现有依赖，无需额外安装）：

```powershell
pnpm exec vite --config ui-preview/vite.config.mts
```

打开 `http://127.0.0.1:5187/`。开发服务仅监听本机地址。

```powershell
pnpm exec tsc -p ui-preview/tsconfig.json
pnpm exec eslint ui-preview/src ui-preview/vite.config.mts
pnpm exec vite build --config ui-preview/vite.config.mts
```

独立构建输出到 `ui-preview/.build/`，不进入正式桌面应用的 `dist` 或安装包。

## 页面与交互

- 总览：状态摘要、模拟检查、暂停/恢复、动态分类、连接与通知入口。
- 动态收件箱：搜索、筛选、完整原文、简短判断说明、复制、来源说明。
- 数据源：即时开关、模拟检查、来源诊断、扩展操作帮助。
- 通知：每类系统通知/声音、演示收件人、SMTP 草稿、模拟测试与送达重试。
- 设置：检查节奏、启动偏好、深浅主题；仅保留「常规与启动」「外观」两个分类。

页面使用 hash 导航；底部可切换监测、确认、预告、异常场景。桌面收件箱中的消息列表和正文分别滚动，刷新、计数、阅读操作固定可见；手机采用列表/详情单页切换。

## 设计系统

- 浅色：中性底色 `#f5f6f3`，白色内容面，青绿强调 `#217763`，深墨绿标题。
- 深色：中性炭灰底色 `#151619`，蓝色强调 `#8ab4ff`，保持相同的信息结构。
- 中文与控件使用系统无衬线字体；英文公告和品牌字标使用 Georgia，区分阅读内容与操作界面。
- 细描边、8–16px 圆角、按时间分组的列表、固定阅读操作区；不用嵌套卡片堆叠信息。
- 状态始终同时提供颜色与文字。动效响应 `prefers-reduced-motion`。

## 数据边界

全部动态、时间、采集指标和送达记录均为示例。原型不读取 Cookie、Chrome 配置、SMTP 凭据或正式数据库；不访问 X/RSS，不发邮件，不注册开机任务。只有用户主动点击「打开 Tibo 主页」才会打开外部站点。

主题、开关与间隔存入独立的 `tibo-watch-ui-preview:v1` 浏览器存储；演示邮箱表单只存在当前页面内存中。SMTP 密码输入被禁用，请勿输入真实凭据。正式版的配置和历史完全不受影响。
